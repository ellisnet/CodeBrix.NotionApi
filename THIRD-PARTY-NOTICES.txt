   The production source code of the CodeBrix.NotionApi assembly (the .cs
   files under src/CodeBrix.NotionApi/) was ported from the
   Src/Notion.Client tree of notion-sdk-net 5.0.0, EXCEPT these
   CodeBrix-authored files, which are new in this repository:
   InternalsVisibleTo.cs, Serialization/RuntimeTypeConverterFactory.cs,
   and the eight Unknown* fallback classes (UnknownRichText.cs,
   UnknownPropertyValue.cs, UnknownProperty.cs, UnknownPropertyItem.cs,
   UnknownFileObject.cs, UnknownFileObjectWithName.cs,
   UnknownFileImportResult.cs, UnknownDataSourcePropertyConfig.cs).

   The test source code under tests/CodeBrix.NotionApi.Tests/ was ported
   from the Test/Notion.UnitTests and Test/Notion.IntegrationTests trees
   of the same upstream version, including these non-source assets:
     - the JSON response fixtures under tests/CodeBrix.NotionApi.Tests/data/
     - tests/CodeBrix.NotionApi.Tests/Integration/assets/notion-logo.png
       (an image bundled by the upstream test suite as file-upload test
       data; the Notion logo itself is a brand asset of Notion Labs, Inc.)
   The test-infrastructure files FakeServer.cs, RecordingRestClient.cs,
   ApiTestBase.cs, and Integration/IntegrationTestBase.cs are
   CodeBrix-authored replacements for upstream's WireMock.Net/Moq-based
   infrastructure.

   Each ported .cs file carries a "//was previously: <upstream namespace>;"
   comment on its namespace line; CodeBrix-authored files do not.

   Non-trivial modifications made during the port:
     - All JSON serialization was migrated from Newtonsoft.Json to
       System.Text.Json; the Newtonsoft.Json dependency was removed.
     - The JsonSubTypes dependency was removed; discriminator-based
       polymorphic deserialization is provided by the new (original,
       non-ported) CodeBrix.JsonPolymorphism library instead.
     - Namespaces were renamed from Notion.Client[.*] to CodeBrix.NotionApi,
       and block-scoped namespaces were converted to file-scoped.
     - [JsonProperty("x")] attributes became [JsonPropertyName("x")];
       [EnumMember(Value = "x")] enum values became
       [JsonStringEnumMemberName("x")]; StringEnumConverter became
       JsonStringEnumConverter; IsoDateTimeConverter attributes were
       dropped (System.Text.Json defaults to ISO 8601); Newtonsoft custom
       converters were rewritten as System.Text.Json converters.
     - [JsonProperty] attributes that upstream declared only on INTERFACE
       members (honored by Newtonsoft as a fallback, ignored by
       System.Text.Json) were propagated onto the implementing classes.
     - Upstream JsonSubTypes fallback declarations that referenced the
       declaring type itself were redirected to new Unknown* subclasses,
       because the System.Text.Json converter cannot dispatch a type to
       itself without recursing.
     - The empty concrete base class Filter was made abstract so the
       runtime-type serialization path applies to it.
     - [JsonConverter(typeof(StringEnumConverter))] attributes that
       upstream placed on STRING-typed properties (tolerated by
       Newtonsoft, rejected by System.Text.Json) were dropped.
     - [EnumMember(Value = null)] enum values were dropped (equivalent to
       the default member-name behavior).
     - The WireMock.Net, FluentAssertions, Moq.AutoMock, and xunit (v2)
       test dependencies were replaced with an in-repo fake
       HttpMessageHandler harness (FakeServer), an in-repo IRestClient
       recording fake (RecordingRestClient), SilverAssertions, and
       xunit.v3; *Test file/class names were renamed to *Tests.
     - The Microsoft.SourceLink.GitHub package reference was dropped.
     - The target framework was narrowed from netstandard2.0 to net10.0.
